# 轴号（块属性 ATTDEF / ATTRIB）：按 V0.1.0 的做法补回

用户报「根据 V0.1.0 调整 V0.2.0 版本的轴号问题」。对照 V0.1.0 的 `docs/修复记录.md` 第 **V54** 节
（`## V54 轴号（块属性 ATTRIB）整批丢失 + 位置二次变换`），V0.2.0 里这三处**全部退化回了修前状态**，
并且多出一条与 ATTDEF 显示有关的连带问题。

## 1. 三处退化（V54 的缺陷①②③）

| # | V54 里的缺陷 | v0.2.0 的现状 | 后果 |
|---|---|---|---|
| ① | ATTRIB 从未导入 | `CadExchange::Convert` 里只有一句 `if (dynamic_cast<const Dwg::AttributeBase*>(&src)) return Skip(src);`，INSERT 分支完全不看 `e->Attributes` | 轴号文字整批消失，图上只剩一个个空圆圈 |
| ② | 位置被 `CellMatrix` 二次变换 | `InsertEntity::Draw` 用 `xsink`（已乘 CellMatrix）画 ATTRIB | 插入比例 1200 时坐标被放大 1200 倍，轴号飞出图面 |
| ③ | Fit / Aligned 的对齐码被丢 | `AttribBase` 没有 hAlign / vAlign 字段，绘制只走左对齐 `EmitMText` | 只换锚点不传对齐 ⇒ 文字从中点向右排，偏出半个字宽、跑出圆圈 |

`test0.dwg` 的实测基线（DWG 真值）：`_AXISO` 实例 **417**、全部带 ATTRIB；全库 ATTRIB **2343**。
v0.2.0 修前这些数字在场景里是 **0**。

## 2. 改动

| 文件 | 改动 |
|---|---|
| `src/Core/Entity/AttribEntity.hpp` | 补 `m_hAlign` / `m_vAlign`（组码 72 / 73、ATTRIB 为 74）与 `SetAlign`/`GetHAlign`/`GetVAlign`；`Draw` 非左对齐时走 `EmitAlignedText`；新增 `AttDefEntity::ShowsInBlockReference()`；**空值 ATTRIB 不画字**（见 §4） |
| `src/Core/Entity/InsertEntity.hpp` | ATTRIB 改在**单元循环之外**用 `sink` 画（坐标已是世界坐标，不得再乘 CellMatrix，也不能随阵列重复）；块内**可变** ATTDEF 模板不画 |

| `tests/Core/AttribAxisTests.cpp`（新增） | 12 项用例，见 §5 |

## 3. 两个容易踩反的语义

**（a）可变属性的模板不该画。** `_AXISO` 块定义 = 圆 + 一个 `tag="A"`、默认值空的 ATTDEF。
可变属性的实际取值由随附的 ATTRIB 提供，把模板也画出来就是「每个轴号旁多一个 A」
（V0.0.1 的 R35，全图 1616 个块参照）。只有**常量属性**（70&2）没有对应 ATTRIB、取值就是模板，才画。

**（b）ATTRIB 的 `10/11` 已是世界坐标。** AutoCAD 在 INSERT 里就把属性定位算好了，
所以 `InsertEntity::Draw` 里它不能进 `TransformDrawSink`。属性也因此**不能**按阵列单元重复画。

## 4. 顺带修掉的一类「凭空多出来的文字」

`AttribBase::Draw` 原来的占位规则是 `m_text.empty() ? m_tag : m_text`。
对 ATTDEF（模板）成立，对 **ATTRIB（实例）不成立** —— 空值表示这一栏没填，AutoCAD 什么都不画。

实测 `test0.dwg`：2343 个 ATTRIB 里 **990 个空值**（图签的「专业负责人1」「图名」「会签人_建筑」…）。
沿用占位规则会把这 990 个**字段名**印到图上。现在改为：ATTRIB 空值不画，ATTDEF 仍显示 tag 占位。

## 6. 已知的语义近似

- **Fit / Aligned 不做逐字拉伸**：取 10↔11 中点后按居中显示（与 V0.1.0 的取舍相同）。
  写出时还原为「插入点 = 对齐点 = 锚点 + 居中」，往返后锚点与居中都一致，只是丢掉 `72=5` 这个标记。
- **属性文字固定用 Standard 样式**（Core 侧 `AttribBase` 没有 styleId），与 V0.1.0 的显示一致。
- 多行属性（`AttributeType::MultiLine`，内嵌 MTEXT）按单行处理 —— MiniDWG 侧本就没有建模。
