# MiniCAD v0.6.0

本版主要改进图层与显示精度。图层可以按名字里的 `$` 分级显示成树（同 Rhino 的子图层），上级的开关、锁定、删除、改名连同下级一起改；锁定图层淡显、不能选中，打开与另存保留锁定标志。测绘坐标（几十万、几百万）的图纸放大后线画偏、夹点不在线上、画线时捕捉晃动的问题修好了；放到最大时圆仍是圆、线交得上，对象捕捉优先于正交 / 极轴（issue #29）。另外改进了文字（`\U+XXXX` 转义、下划线 / 上划线 / 删除线、TrueType 缺字、镜像块里的文字）与天正对象的显示（墙柱填充、幕墙、门槛线、尺寸文字位置与颜色等），天正自带的填充图案编进了程序。

### 新增

- **图层分级（同 Rhino 的子图层）**：图层名里用 `$` 分隔各级（如 `建筑$墙$外墙`），Rhino 导出 DWG 时子图层就是这样写的，文件格式不变，与 AutoCAD、Rhino 往返都不丢层级
  - 图层面板的名称列显示成树：按层级缩进，点箭头或按 → / ← 展开折叠，右键菜单可全部展开 / 折叠；只有 `A$B` 没有 `A` 时补一行分组，它的开关、锁定显示下级的总体状态；搜索时全部展开
  - 上级的开关、锁定、删除、改名连同下级一起改，一步撤销；下级不继承上级的状态，文件里存的就是每个图层实际的开关，AutoCAD 里看到的相同
  - 改名只改这一级，名字里带 `$` 即再往下分级；工具行与右键菜单的"子图层"新建 `上级$图层N` 并进入改名
  - 功能区与特性面板的图层下拉框也按层级缩进，收起时写全名
- **锁定图层**：打开 DWG / DXF 时读入图层的锁定标志，另存时写回（以前没读，锁定的图层与普通图层一样）
  - 锁定图层上的对象淡显（不透明度减半，同 AutoCAD 的 `LAYLOCKFADECTL` 默认 50），块参照在锁定图层上时整块淡显
  - 锁定图层上的对象点选、框选、悬停都选不中，工具也点取不到，但仍能捕捉；图层锁定后，已选中的该层对象移出选择集
  - 锁定 / 解锁图标改得一眼能分清：锁定为琥珀色实心闭合的锁，解锁为灰色空心、锁梁抬起的锁
- **天正自带的填充图案编进了程序**：天正 acad.pat 里的图案（钢筋混凝土、普通砖、加气混凝土、卵石砌体等 114 个）在填充对话框里可选，网页版同样有；天正墙柱按图纸设置填充时直接用这些图案，不用再往 `patterns` 目录放天正的 acad.pat。与 AutoCAD 同名的标准图案（ANSI31 等）天正改成了 acadiso 的一半，只在天正填充里按天正的用
- **文字**
  - 多行文字、单行文字里的 `\U+XXXX`（代码页外字符的写法，如 `\U+8D1F\U+4E00` 即"负一"）还原成文字，以前显示成 `+8D1F+4E00…`
  - 画出下划线 `\L`、上划线 `\O`、删除线 `\K` 与单行文字的 `%%u`、`%%o`，位置按 AutoCAD 分解量得
  - TrueType 字体里没有的字（如 Arial 写中文）用自带的 GB2312.ttf 补上，不再画成方块；`%%d` 等控制码在 TrueType 字体里也不再画成方块
  - 镜像的块参照（负比例、法向朝 -Z）里的文字跟着翻转，与 AutoCAD 一样画成镜像；旋转的多行文字按附着点定位时偏移随文字旋转

### 改进

- **测绘坐标的图纸显示准确**：坐标几十万、几百万时，顶点改为相对图形附近的"渲染原点"存，原点再在双精度里合进视图矩阵。以前放大后线画偏几十个像素，夹点、捕捉标记看起来不在线上，画线时预览线一格一格地跳；地形测试图在约 4.7 个单位宽的视图里，线离应在的位置从平均 20 像素（最多 43）降到 0.2 像素。新建的图纸里画到测绘坐标上时自动换原点
- **放到最大时圆仍是圆、线交得上**（issue #29）：全图的显示按常规缩放细分（圆每圈 64 段），放大到误差超过约半个像素、视图附近的实体又不多时，只把视图附近的实体按当前缩放重新细分：原点移到视图附近，圆、圆弧、椭圆、多段线的圆弧段（含带宽度的）在视图附近加密到弦高不超过 1/4 像素；缩小回来时恢复全图显示，不重新细分整张图。原点附近的图纸放到最大（可视高度 0.01）时，圆离真圆不到 0.2 像素、直线不到 0.01 像素（以前分别差 2500 像素与几到几十像素）；测点圆盘的边缘离真圆平均 0.24 像素（以前是 5° 一段的折线）。大图纸平常平移、缩放的耗时不变
- **对象捕捉优先于正交 / 极轴**（issue #29）：捕捉到端点、交点、圆上的点时不再把点挪到水平 / 竖直线或极轴角度上（同 AutoCAD），开着极轴画到端点不会再差一点或冒出一点；网格捕捉照常受约束
- **天正对象的显示**（与天正 2014 的显示逐项核对）
  - 墙、柱按图纸设置的"填充"开关填充，按材料取标准或详图图案，放在 PUB_HATCH 图层
  - 门窗洞口两侧的墙端封口；墙接着不同材料的墙时画分界线；门槛线按门窗标志画在门扇一侧或对面，没有标志时不画
  - 幕墙按连接量与相邻墙交接，非玻璃幕墙按墙画并填充，玻璃幕墙的 4 条线按连接量缩进或伸出
  - 尺寸文字用天正里拖动过的位置；竖向尺寸方向带浮点误差时不再翻到尺寸线另一侧
  - 尺寸数字按标注样式的文字颜色（`DIMCLRT`）画，轴号编号放在轴号的文字图层上、随层，以前都是白色；角度标注按 `DIMAZIN` 去零（"90.00°" 显示为 "90°"）
  - 文字各段画出的宽度取天正的步进（替代字体宽窄不同时不再压到下一段），画出上标 `^U`（m² 等），引出标注的字宽乘样式宽度
  - 矩形按矩形标志画对角线（套管图例的"×"）

### 修复

- **图层在位改名按 Enter 提交时崩溃**：先输入重名被拒绝、改好后按 Enter 就会碰到；改名被拒绝时也不再把文档标成已修改
- **开着极轴时捕捉到的点被挪走**（issue #29）：见上面"对象捕捉优先于正交 / 极轴"

### 开发与测试

- 渲染原点：`ToRenderFloat3`、`DrawContext::SetRenderOrigin`、`ViewState::RenderOrigin`，`Viewport::Render` 把原点合进矩阵；`Editor::ChooseRenderOrigin`（可见实体中心的中位数，取 4096 的整数倍，原点附近的图纸仍是 0）、`Editor::NeedsRenderRebase`；`Overlay` 内部改存双精度；`Editor::GetRenderOrigin`，`Editor::ForEachCachedVertex` 给出世界坐标
- 深度放大：曲线细分 `SampleCurve` / `SampleCurveSpans`（`src/Core/Draw/CurveSampling.hpp`），`IDrawSink::RefineCurveSegment`（`TransformDrawSink`、`ClipDrawSink` 转发），`DrawContext::SetCurveRefinement`；局部显示 `Editor::UpdateLocalDisplay` / `EvaluateLocalRegion` / `LeaveLocalDisplay`，全图的逐实体缓存收起来、回来时重新拼接；`SpatialIndex::Query` 加数量上限，`Picking::GetIndexedBox`
- 图层：`src/Scene/LayerPath.h`（`$` 分级的路径运算）、`LayerOps::ChangeTree` / `DeleteTree`、`RenameLayerTreeCommand`；MiniGUI 的 `ListView` 加树形列（`SetTreeColumn`）；`InlineEditor`、`ListView` 修复回调里重建行时的重入
- 文字：`src/Core/TextCodes.h`、`TextLayoutEngine` 输出 `DecorationLine`、`IDrawSink::ToggleTextMirror`
- 排查工具：`MiniCADDwgInspect` 加 `MINICAD_GREPTEXT`、`MINICAD_DIM`，`MINICAD_H` / `MINICAD_HATCH` / `MINICAD_WALLRAW` 打印更多字段，DIMSTYLE 行打印 `azin`、`clrt` 等；`--bench` 加 `MINICAD_BENCH_VIEWS`（按世界坐标窗口截图，打印画面角点坐标）
- 单元测试补渲染原点与深度放大（按 GPU 的 float 运算核对场景线、选中流、夹点、画线预览与放到最大时的圆）、开着极轴捕捉端点、图层路径与上下级命令、在位改名的重入、锁定标志往返与淡显、文字转义与装饰线、天正墙柱填充 / 幕墙 / 尺寸文字颜色、内置天正图案；桌面版自测加第 9.2 节（图层树、折叠、分组行的锁、重名改名、下拉框缩进）
