# MiniCAD v0.7.0

本版主要加了多语言界面：英文、繁體中文、日本語、한국어。菜单、功能区、命令行提示、对话框、特性与图层面板、节点编辑器、状态栏，以及打开图纸时的警告和出错原因都能按所选语言显示，命令行提示和术语按 AutoCAD 各语言版本的写法。图纸数据不受影响：中英文版本打开同一张图，结果相同。

### 新增

- **界面语言：简体中文 / English / 繁體中文 / 日本語 / 한국어**
  - **切换**：在标题栏右侧的"设置（齿轮）> 语言"里选，立即生效，不用重启。打开的文档、停靠布局和文档窗口都保持原样，选择会记下来，下次启动沿用
  - **默认**：没选过时跟随系统语言。系统是繁体中文（台湾、香港、澳门）时用繁體中文，日文、韩文系统用对应语言，其他中文用简体中文，其余语言用英文
  - **命令行参数**：启动时加 `--lang en`、`--lang zh-CN`、`--lang zh-TW`、`--lang ja` 或 `--lang ko`，也可以设环境变量 `MINICAD_LANG`。这两种只管这一次，不改设置
  - **网页版**：同样在"设置 > 语言"里切换，选择存在浏览器里；网址加 `?lang=en` 时优先用它
- **英文界面的范围**
  - 主窗口：菜单、功能区、标题栏、起始页、状态栏、视图方块、模型 / 布局标签、文件对话框
  - 编辑器：各工具的命令行提示与回显、动态输入、特性面板、图层面板、各对话框、打开 / 保存失败的原因
  - 节点编辑器：节点的名称、分类、说明、端口、参数，节点上的出错信息，节点面板，示例。搜索节点时中英文都能搜到
  - 诊断信息：读写 DWG / DXF 的警告与出错原因、三维实体内核的出错信息、图形接口创建失败的提示、填充图案文件的解析错误，都按当前语言显示
- **新版本提示**：桌面版与 Linux 版启动时在后台检查 GitHub 上的最新发布，有新版本时标题栏右侧的版本号旁出现红点，点它查看更新说明并一键下载；也可以在"文件 / 帮助 > 检查更新"里手动检查
- **命令行选项字母不变**：英文提示写成 `[Close(C)/Undo(U)]`，按的还是原来的字母；命令名、快捷键也不变

### 改进

- **新建图纸的布局名按当前语言起**：英文界面下新建的图纸，布局叫 `Layout1`、`Layout2`（同 AutoCAD 英文版）。布局名建好后就是图纸里的数据，之后切换语言不会改；打开已有图纸时，"布局1"这类名字照原样显示
- **写进图纸的数据不翻译**：图层名、样式名、文字内容、布局名照原样保存与显示，中英文版本之间来回打开保存，图纸内容不变
- **天正对象**：扩展了天正对象的解析，柱、矩形、幕墙显示得更准确
- **界面字体**：网页版按新的界面文字重新生成了子集；韩文在桌面版用系统的 Malgun Gothic，网页版与 Linux 版随程序带一个韩文字体子集

### 说明

- 英文、繁體中文、日文、韩文翻译由 AI 按 AutoCAD 各语言版本的术语初译。哪里用词不妥或漏了中文，欢迎提 issue 并附上截图或那句英文
- 不随界面语言变的：自测（`--selftest`）与 `--bench` 的输出仍是中文；各工具给开发者看的跟踪日志改成了英文
