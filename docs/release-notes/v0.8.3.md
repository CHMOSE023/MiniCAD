# MiniCAD v0.8.3

本版重做了多行文字的显示，行距和段内格式（字体、字高、颜色、分数与上下标、缩进）都对照 AutoCAD 2020 实测做了校准。另外补上了天正 T20 各版本的更多对象，并修正了代理图形、真彩黑白、块裁剪和填充的几处显示差异。

### 修复

- **多行文字行距过小，中文行行重叠**（#40）：行距改按 AutoCAD 的规则计算，单倍行距约为 1.67 倍字高，含大字或分数的行会自动加高；图纸里的行距比例和"至少 / 精确"设置现在会读入，另存时也会写回
- **多行文字的段内格式被忽略**：段内单独设置的字体（比如在 SHX 样式里改用宋体的一段）、字高、宽度、倾斜、字间距、颜色以前只认开头的宽度，其余全部丢掉，现在逐段显示
- **代理图形缺线**：两种字节顺序的记录都能读出，轻量多段线（含圆弧段和逐段宽度）能画出；遇到不认识的记录只跳过那一条，不再整个放弃
- **真彩黑、白被当成 7 号色**：真彩 0,0,0 和 255,255,255 不再随背景反色，在深色背景上仍按原色显示，与 AutoCAD 一致
- **块裁剪（XCLIP）后多段线没截断**：多段线按裁剪边界逐段截断，闭合段和凹形边界也能处理，带宽度的线截断后保留宽度
- **填充线压在边界上**：与边界重合的图案线不再画出，与 AutoCAD 一致

### 新增

- **多行文字的分数、上下标与公差**：`m²` 这类上标、横线分数、斜线分数和公差堆叠按 AutoCAD 的位置排布，支持底 / 中 / 顶竖向对齐
- **多行文字的段落缩进与对齐**：支持首行缩进、悬挂缩进，以及按段落左对齐、居中、右对齐
- **天正 T20 各版本对象**：能读出更多版本的天正墙、坐标标注、箭头、矩形楼梯、索引符号、指北针、文字和直径标注；新增老虎窗、房间、曲面网格的显示
