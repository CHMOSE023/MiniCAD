# MiniCAD v0.8.4

本版让保存为 AutoCAD 2000 格式的天正图纸也能显示天正对象，并修正了多行文字选中范围不准、原位编辑显示格式码的问题。

### 修复

- **2000 格式的天正图纸缺对象**：天正图纸常另存为 DWG2000 格式，以前这类图纸里的墙、门窗、楼梯、标注、符号等天正对象一律不显示，现在与 2004 格式一样读出。给排水的井、设备、阀门等少数对象在 2000、2004 格式里仍不显示
- **多行文字在文字外面也能选中**：选中范围以前按文字的参考框宽度算，参考框比文字宽很多（尤其旋转过的文字）时，离文字很远处一点就选中；现在按文字实际占的范围判断，点选和框选都一样
- **原位编辑框位置不对**：编辑已有的文字时，编辑框有时出现在别处，现在出现在文字上，宽度也不会超出绘图区
- **原位编辑和特性面板显示格式码**：带段内格式的多行文字，编辑框和特性面板的"内容"以前显示 `{\f宋体|b0|…;文字}` 这样的原始格式码，现在只显示文字；改完后只替换改动的那几个字，原来的字体、字高、颜色等格式照旧保留。表格单元格的编辑同样处理
