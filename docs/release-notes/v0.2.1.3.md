# MiniCAD v0.2.1.3

v0.2.1.2 之后的功能与修正版本：支持图纸的点样式（`$PDMODE` / `$PDSIZE`）与全局线型比例（`$LTSCALE`），修复图案填充里的"点"（如 DOTS 点阵）看不见、选不中。桌面版与网页版都包含这些改动。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.2.1.3-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.2.1.3-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 新功能

- **点样式**（格式 → 点样式…，命令 `PointStyle`）：与 AutoCAD 的 DDPTYPE 相同的 20 个图标（4 种外框 × 5 种基本形），点大小可选"相对于屏幕"（视口高度的百分比，缩放时大小不变）或"按绝对单位"。打开 DWG / DXF 时读取 `$PDMODE` / `$PDSIZE`，以前所有 POINT 都画成固定大小的十字，现在与 AutoCAD 显示一致（例如 `$PDMODE = 34` 画成 ⊕）；DEFPOINTS 图层上的点始终画成小点
- **全局线型比例**（格式 → 线型比例…，命令 `LineTypeScale`）：虚线周期 = 线型图案周期 × 实体线型比例 × 全局比例，对话框带预览。打开图纸时读取 `$LTSCALE`，大尺寸图纸（全局比例常为几百上千）的虚线以前密到退化成实线，现在能正常显示
- 两个对话框的改动实时预览，点"确定"后可以撤销；`$PDMODE`、`$PDSIZE`、`$LTSCALE` 在另存 DWG / DXF / `.mcad` / JSON 时都会写回

## 修正

- **图案填充的"点"看不见**：`.pat` 里 dash = 0 的点（DOTS 等）以前画成极短的线段，视图缩小后不到 1 像素就整片消失；纯点阵图案甚至一个点都不画。现在点用点图元绘制，始终是 1 个屏幕像素，点间距与图案定义一致
- **点阵填充选不中**：悬停、点选、框选都能选中只由点组成的填充
- **填充边界线**：扫描线与填充边界重合时（例如矩形的底边、顶边）也会画出；扫描线正好穿过多边形顶点时不再错位填到边界外面
- 被区域覆盖（Wipeout）盖住的填充点会被正确裁掉；选中、悬停时点和点样式图形也会高亮
