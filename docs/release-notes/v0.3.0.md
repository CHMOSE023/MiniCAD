# MiniCAD v0.3.0

### 新增

- **全新界面风格**：参照 SolidCraft 重做主窗口布局——绘图区铺满标题栏以下，功能区、停靠面板、状态栏都是浮在绘图区上的圆角卡片；图标全部换新
- **功能区**（Ribbon）：命令按选项卡分组，右端有收起按钮和命令搜索框（Ctrl+K）
- **起始页**：新增首页（标题栏“首页”按钮），显示时隐藏其余界面
- **视图导航条**：视图方块下方新增竖排导航条；标题栏右侧新增 AI / 设置 / 帮助 / 版本入口
- **布局**：模型 / 布局标签常显，支持增删布局；布局按二维图纸处理
- **多线**：完善多线绘制与编辑，多线参数随 `.mcad` 保存
- **SubD 网格（MESH）**：DWG / DXF 全链读写与显示，线框按原图边表绘制，导出时还原原来的面
- **多重引线（MULTILEADER）**：DWG / DXF 导入导出，文字随引线编辑、夹点、旋转、镜像正确跟随
- **视图切换过渡动画**
- **SMLib 升级到 1.0.1**

### 完善

- 块与视口的多项修复：块内定位 / 线型、裁剪显示与编辑、文字折行、双击中键缩放
- 实体旋转可输入轴线
- 修复布局视口显示（视图中心换算、内容旋转方向、可见区域）
- 修复融合起点与参数导致的侧面问题
- SMLib 内核临时目录先用系统 TEMP，写不了再用 `tmp` 目录
- 构建依赖修复；桌面版端到端自测程序优化
