# MiniCAD v0.8.2

本版补全了天正暖通图纸的显示：2004 格式图纸里的管线、风管标注和多种风管管件以前读不出来，现在都能显示。

### 修复

- **2004 格式天正图纸的管线、管件、管线文字不显示**：这类图纸的文字存放方式与新版本不同，以前读错后整个跳过，现在按原样显示
- **天正风管管件读不出来**：明文保存的管件以前读到一半就失败，现在都能读出

### 新增

- **天正风管标注**：单行的风管尺寸文字居中、正读显示；带引线的表格式标注画出引线和两行两列的表格
- **天正风管三通、四通、乙字弯**：三通支持直角、弧形、Y 形等支管样式，四通按两侧支管画出；乙字弯在平面上画成两段圆弧，竖向偏移时画直管加 Z 形符号
