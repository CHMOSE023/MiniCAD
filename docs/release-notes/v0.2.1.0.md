# MiniCAD v0.2.1.0

v0.2.0 之后的版本。主要降低显示大图纸时的内存占用：以天正建筑样图 `8#楼-A平面图.dwg`（4.7 MB，2019 个实体）为例，显示后的私有内存从约 830 MB 降到约 295 MB。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.2.1.0-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.2.1.0-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 性能与内存

- **矢量文字按字形实例化**：每个字不再展开成世界坐标的三角形和线段，而是输出一条字形实例（36 字节的变换 + 颜色）；同一字体的同一个字形，网格只存一份（`GlyphMeshLibrary`）。桌面版用 `DrawInstanced`、网页版用 `drawArraysInstanced` 绘制。上述样图中 47044 个字共用 906 份字形网格，场景顶点从约 717 万降到约 161 万
- **顶点颜色改为 RGBA8**：`Vertex_P3_C4` 从 28 字节降到 16 字节
- **场景静态流上传 GPU 后释放 CPU 端副本**：只保留逐实体缓存，需要时从缓存重新拼接，不重新细分
- 被区域覆盖遮住的文字仍按顶点裁剪；选中的文字仍按顶点绘制

## 构建与版本

- 桌面版 exe 版本号第四段改为构建号（git 提交数），例如 `0.2.1.152`；之前固定为 0。产品版本仍为三段（`0.2.1`）。版本头文件在每次构建时重新生成（`cmake/MiniCADVersion.cmake`），新提交后不用重新配置；CI 改为完整克隆，以取得提交数

## 测试与诊断

- `MiniCADWin.exe --bench` 额外打印各顶点流数量、字形实例数与字形网格数
- 自测适配 v0.2.0 起启动时不再创建演示文档的变化：没有活动文档时先新建一个

## 已知问题

- 自测中有 2 项已知失败（阵列对话框默认值、改颜色后的重新细分）
- 截图对比测试 `MiniGUIGolden` 有 10 个场景与基准图不一致（标题栏、停靠、文档标签），CI 不运行该测试
- `--bench` 只有在 `MiniCADWin.exe` 所在目录运行时才能找到 `fonts/`，否则文字不显示，测得的内存偏低
