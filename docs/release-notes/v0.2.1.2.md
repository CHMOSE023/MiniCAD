# MiniCAD v0.2.1.2

v0.2.1.1 之后的修正版本，只改网页版：修复发版后部分浏览器（如 Edge）打不开网页版，并新增加载画面。桌面版功能与 v0.2.1.1 相同。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.2.1.2-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.2.1.2-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 网页版

- **修复发版后打不开**：浏览器控制台报 `LinkError: WebAssembly.instantiate(): Import #97 "a" "Ra": function import requires a callable`，页面停在"Downloading data..."。原因是 Cloudflare 的浏览器缓存 TTL 让 `index.js` 缓存 4 小时，而 `index.wasm` 不缓存，浏览器拿旧的 `index.js` 去加载新的 `index.wasm`，导入表对不上。现在构建后给 `index.js`、`index.wasm`、`index.data` 的地址加上内容哈希参数（`?v=...`，由 `cmake/WebCacheBust.cmake` 写入），每次发版地址都不同，不会再混用新旧文件
- **加载画面**：旋转的 MiniCAD 图标，下方显示下载百分比与进度条；加载失败时显示原因，提示刷新重试，不再停在一行英文状态文字上

如果已经遇到上面的错误，升级后刷新一次即可；仍不行时按 Ctrl+F5 强制刷新。
