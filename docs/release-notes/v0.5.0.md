# MiniCAD v0.5.0

本版的重点是多窗口（Windows 版）：文档标签可以拖出主窗口成为独立的系统窗口，放到第二台显示器上；每个窗口都是完整的——标题栏、功能区、停靠面板、命令行、状态栏一应俱全，标签能在任意窗口之间拖动合并。停靠面板也能拖出窗口单独浮动。另外大图纸上画图、修改、撤销明显变快。

网页版、Linux 版给不出独立窗口，仍是单窗口，行为与以前相同。

### 新增

- **文档拖出成独立窗口**（Windows 版）：像 Chrome / Visual Studio 那样，把文档标签拖出标签条，鼠标还没松开窗口就出现并跟着光标走；标签右键"在新窗口中打开"也行
  - 一个窗口里可以放几个文档；任何窗口的标签都能拖到任何窗口的标签条上合并（画插入标记），窗口里只剩一个标签时，拖这个标签就是拖整个窗口
  - 每个窗口都有自己的标题栏（"文件"菜单、快速访问、文档标签、最小化 / 最大化 / 关闭）、功能区（含图层 / 线型 / 线宽下拉框）、视图方块、导航条、命令行、动态输入框、状态栏（含模型 / 布局标签），以及停靠的特性、图层、节点编辑器面板，都显示这个窗口里的文档；快捷键在每个窗口里都能用
  - 拖动标题栏交给系统：双击最大化、拖到屏幕边缘贴边分屏；拖到别的窗口的标签条上松开，它的文档全部合并过去
  - 在哪个窗口里操作，哪个窗口的文档就是当前文档；新建、打开的图纸进你正在用的那个窗口，打开 / 另存为对话框也开在那个窗口上
  - 文档窗口与主窗口平级（任务栏里有自己的按钮），不会挡住主窗口弹出的对话框；关闭文档窗口 = 关闭它里面的文档（未保存的逐个询问）
  - 主窗口里没有文档（都拖到别的窗口了）时显示起始页
  - 下次启动时所有文档都回到主窗口（不保存文档窗口）；程序自己画的对话框（保存提示、图层、文字样式等）仍开在主窗口里，弹出时主窗口自动置前
- **停靠面板可以浮出**：特性、图层、节点编辑器等面板的标签拖出停靠区（同样鼠标没松开就浮出，窗口跟着光标走）或双击标签，面板浮出成浮动窗口
  - Windows 版是独立的系统窗口，可以拖到窗口外、放到别的显示器上；网页版、Linux 版在窗口内浮动
  - 拖浮动窗口的标题栏回到停靠区停靠（画落点预览），双击标题栏回到浮出前的位置；关闭后从"视图 > 面板"再打开时回到原处；位置随面板布局保存
  - 浮出的面板里的调色板、菜单开在面板所在的窗口里
- **大图纸上画图、修改更快**（Windows 版的 D3D11 / D3D12）：新画的图形只把自己的顶点接到显卡缓冲末尾，修改 / 删除 / 撤销 / 夹点拖动只改写实体在缓冲里的那一段，不再整张图重新拼接、上传
  - 3000 万顶点的图纸：画一条直线后的下一帧 345 → 27 ms；移动、删除、撤销、夹点拖起与放下 400～460 → 约 60 ms
  - 带区域覆盖、纹理文字 / 图像的改动仍整张重拼；Linux（Vulkan / GLES3）与网页版（WebGPU / WebGL2）还没有这项优化
- 窗口太矮放不下视图方块下面的导航条时，导航条自动隐藏，不再压住命令行

### 修复

- **未闭合边界的填充画成横跨图纸的大块实心**：图纸里编辑后残留的"未闭合"填充边界（各段散落在图纸各处、缺口与整条路径同一量级）以前被硬接成一个区域，现在与 AutoCAD 一样不画；小缺口（AutoCAD 的间隙容差以内）照常用直线接上

### 开发与测试

- 多窗口的计划与各阶段做法见 `docs/MultiWindow/PLAN.md`；实现说明在 `.agents/features/main-window.md`
  - `DocumentManager` 改成窗格模型：每个窗口一个窗格（视口），窗格里的文档轮流用它，切换时保存 / 恢复各自的相机（`DocumentManager::CreatePane` / `MoveDocument` / `GetShownDocument` / `PaneOf` / `SetNewDocumentPane`）
  - 每个窗口的界面按界面描述文件 `assets/ui/minicad_ui.json` 里新增的 `layouts.document` 一段生成；每个窗口一套绘图区界面（`MainFrame::ViewChrome`）与面板状态（`MainFrame::PanelSet`）
  - `AppPlatform::CreateFloatingWindow` / `IFloatingWindow`：带自己 `UIContext` 的系统窗口（Win32：`Win32FloatingWindow`），能最小化 / 最大化、标题区域交给系统、上报系统移动循环；`IGraphicsDevice::CreateWindowSurface` 每个窗口一个交换链
- MiniGUI：
  - `UiLayout` 支持顶层 `layouts` 里的命名布局（`UiLayout::SetLayoutName`，命令覆盖只由默认布局负责）
  - `CommandRegistry::BindShortcuts` 可以绑定几张快捷键表（每个窗口一张），`ShortcutTable::SetGate` 让宿主加生效条件
  - `TitleBar::SetWindowActions` 按窗口指定最小化 / 最大化 / 关闭的动作；`TabView` 支持标签拖出与跨窗口落点
  - `DockSpace` 浮动面板（`IDockFloatHost`，默认窗口内的 `FloatingPanel` 弹层）；标签拖出停靠区即浮出并由停靠区接着拖（`DockSpace::IsTornDragging`）
- TrueType 字体解析改用本文件私有的 `stb_truetype` 副本（`STBTT_STATIC`），不再与 MiniGUI 里的同名符号冲突；SHX 字体解析补一处形数的越界检查
- 渲染器接口新增 `IRenderer::AppendCached` / `IRenderer::WriteCached`（D3D11、D3D12 实现）；`--bench` 增加选中、移动、夹点拖动、删除、撤销几项
- 桌面版自测新增第 29～31 节（文档窗口、多窗口拖动合并、面板拖出窗口），单元测试补窗格、快捷键表、命名布局、面板拖出等用例
- 已知：真实鼠标的拖动只有自测里的模拟消息验证过；两个窗口同时显示大图纸时，几个视口共用渲染器的顶点缓冲，轮流重画会重新拼接，可能变慢（`docs/MultiWindow/PLAN.md` 第 5 节）
