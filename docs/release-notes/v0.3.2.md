# MiniCAD v0.3.2

本版围绕布局页（图纸空间）的显示：缩放性能、OLE 对象、线型与文字样式的导入。

### 性能

- **布局页滚轮缩放**：视口把模型空间内容合成进自己的显示数据，以前只要里面有一段长虚线或一个相对尺寸的点，整个视口就被标成"随视图变化"，每格滚轮都把视口看见的模型重新合成一遍。现在长虚线照常延迟铺设、合成后按视口矩形裁剪（裁掉前半段时相位接着原线算），相对尺寸的点按视口的纸面高度换算，视口的显示数据不再随缩放重建。0525 总平面图布局页每格滚轮：339 → 16.6 ms（模型页 16.5 ms）

### 新增

- **OLE 对象**（OLE2FRAME，图纸里嵌入的 Word / Excel 文档等）：从 AutoCAD 的头里取出四个角点，从 OLE 复合文档里取出展示图（WMF / EMF / DIB），显示为贴着快照的矩形（`OleFrameEntity`）。位图直接解码；图元文件由平台光栅化（桌面版 GDI 回放，长边 4096 像素），网页版没有图元文件回放时只画边框与对角线。随 `.mcad` / JSON 保存；另存为原格式原版本时原样写回
- **$PSLTSCALE**：读入并写回。为 0 的图纸里布局页视口内的虚线跟着视口比例缩（1:500 的视口里细到接近实线），为 1（默认）时按图纸单位铺
- **布局保存的视图**：进布局页时按图纸里保存的图纸空间视图（AutoCAD 布局主视口的中心与高度）显示，与 AutoCAD 打开布局看到的一致；以前按纸张范围框住，内容画在纸张外的图纸进布局是一页空白
- **外部参照（XREF）**：宿主图纸里的外部参照块按文件路径（绝对路径、相对宿主目录、同目录同名文件）读入外部 DWG / DXF 的模型空间显示；外部图纸的图层、线型、文字样式、块按「参照名|原名」登记，宿主里已有的依赖图层直接复用（颜色、开关以宿主为准），外部图纸的图层 0 并入宿主的图层 0；嵌套的外部参照递归读入（叠加型不随宿主再被参照时显示，已卸载的不显示，循环引用跳过）。另存为其他版本时外部参照仍写成外部参照，不绑定；找不到外部文件时只剩块参照的空框并 `LOG_WARN`
- **系统字体目录**：图纸引用而程序没有自带的 TrueType 字体（simhei.ttf、arial.ttf、STHUPO.TTF …）到 Windows 字体目录（`%WINDIR%\Fonts` 与当前用户安装的字体）里找，不必复制进程序目录（`AppPlatform::GetSystemFontDirs`）

### 修复

- **布局视口的视图中心**：VIEWPORT 的视图中心（组码 12/22）是以视图目标点（17/27/37）为原点的 DCS 坐标。多数视口目标点是原点，但经 DVIEW / 动态观察过的视口目标点落在模型上、12/22 只是相对它的小偏移，以前漏加目标点，这种视口对到了世界原点附近、里面只剩零星几笔（实测 0525 总平面图的"竖向布置图"视口 effb9）。导出时目标点写 (0,0,0)、12/22 写完整位置，不再两处都写
- **视口内冻结的图层**（VPLAYER，组码 331）：每个视口只显示没在本视口冻结的图层，块里的子实体同样过滤；以前每个视口都显示全部图层。随 `.mcad` / JSON 保存，导出时写回
- **天正符号标注的线型**：坐标标注、箭头、剖切符号、引出标注、索引、图名、标高、指北针等符号的线按实线组装；以前沿用对象自身的线型，对象线型是 `__DASH` 的坐标标注引线显示成虚线（原图是实线，实测 0525 总平面图的 F656B）
- **含形的复杂线型**（如 `1161`、`444`、`447`）：以前丢掉形 / 文字所在的元素，周期变短、dash / gap 错位，只有形的线型整条消失；现在保留这些元素的长度（形本身仍不画，0 长度的形显示为点）
- **文字样式导入**：
  - TrueType 样式按字体族名选字体时 STYLE 的文件名为空，族名在扩展数据里（SimSun、SimHei、KaiTi_GB2312 …）；现在换算成字体文件名（simsun.ttc、simhei.ttf、simkai.ttf …），样式对话框里能看出是什么字体，桌面版也能从系统字体目录找到
  - 与预置样式同名（Standard、GB2312）的样式以前整个按预置的，图纸里宽度因子 0.7、字高 5 的 GB2312 会按宽 1、高 0 显示；现在字高、宽度因子、倾斜按图纸的，图纸没给字体时才保留预置字体
  - 图纸里没有的预置样式（Simplex、GB2312）不再留在样式表里（以前另存时还会写进 DWG）
  - 天正文字的显示宽度因子以前派生成 `黑体_W70`、`_TCH_DIM_W71` 之类的文字样式；现在写在多行文字实体上（`MTextEntity::SetWidthFactor`，导出 DWG / DXF 时写成开头的 `\W0.7;`），样式表与图纸一致

### 开发与测试

- 新增 `CadXrefTests`：本机有 `tests/Data/Xref.dwg`（相对路径参照 `Xref-A.dwg` / `Xref-B.dwg`）时核对外部参照的读入、依赖图层复用、符号实线与重新生成导出
- 新增 `OleFrameTests`：OLE2FRAME 头、DIB 解码、`LayPattern` 起点相位、OLE 对象 JSON 往返、视口目标点换算与冻结图层往返；本机有 `tests/Data/0525最终改总平面图.dwg` 时再核对 5 个 OLE 对象、文字样式、线型与视口（effb9 的视图中心、冻结图层）的导入
- `--bench` 增加布局页的滚轮与平移测量；`MINICAD_BENCH_SHOT=目录` 把模型页、布局页与第一个 OLE 对象的视口存成 BMP，`MINICAD_BENCH_PAUSE=秒` 在布局页停留
- `MiniCADDwgInspect`：`MINICAD_TABLES=1` 打印 DWG 与导入后的文字样式 / 线型表，`MINICAD_OLEDIR=目录` 导出 OLE2FRAME 的原始数据，`MINICAD_VIEWPORTS=1` 打印全部 VIEWPORT 的视图参数（目标点、方向、冻结图层）
