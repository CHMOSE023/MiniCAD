# MiniCAD v0.7.1

本版新增安卓版：手机上打开 DWG / DXF 图纸浏览；另外修好了经中望看图另存后的天正图纸打开不显示的问题。

### 新增

- **安卓版**（`MiniCAD-v0.7.1-android-arm64.apk`）：Android 10 及以上的 arm64 手机、平板，下载后安装（要允许"安装未知应用"）
  - **手机只浏览**：窄屏时换成简化界面，用"文件"或其他应用打开 DWG / DXF，单指拖动平移，右侧工具条放大、缩小、全部显示
  - **全屏**：右侧工具条最下面的按钮隐藏状态栏和导航栏，返回手势先退出全屏
  - **多个图纸**：标题栏里并排显示，打开两个以上时右侧的"⌄"列出全部；最近打开的图纸列表升级后不丢
  - **新版本提示**：启动时检查 GitHub 上的最新发布，有新版弹出提示，可以下载或忽略这个版本
  - 平板和接了鼠标键盘的设备用完整界面
  - 说明：本版的安装包用 CI 的临时密钥签名，以后的版本签名可能不同，届时要先卸载旧版再装新版

### 修复

- **DWG2004格式**， 墙、柱、门窗、符号等对象不显示。
- **"全部显示"偏到一边**：多段线里有两个重合的顶点且中间一段带凸度（云线、修订标记里常见）时，全部显示的范围被拉到坐标原点，图形挤在窗口一角
