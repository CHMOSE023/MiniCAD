# MiniCAD v0.2.0

v0.1.1 之后的版本。统一版本号来源、核心库目标改名并迁入 `cmake/MiniCAD.cmake`，同时调整了默认设置与界面（见"行为变化"）。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.2.0-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.2.0-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 行为变化

升级后以下默认行为与 v0.1.1 不同，如需恢复请在对应位置改回：

- **对象捕捉默认关闭**（`src/Editor/Snap/SnapEngine.h`）
- **悬停高亮默认关闭**（`src/Editor/Picking/Picking.h`）
- **细线显示默认开启**：忽略线宽，全部按 1 像素显示（`src/Editor/Editor.h`）
- **启动时不再生成演示图形**（`apps/Common/src/GUI/MainFrame.cpp`）
- **属性面板的"绘图辅助"分组暂时隐藏**（对象捕捉、正交、悬停高亮、捕捉孔径；`apps/Common/src/GUI/MainPanels.cpp`）
- **标准工具栏去掉"对象捕捉""正交"按钮**（`assets/ui/minicad_ui.json`）

## 界面

- 工具栏的"新建""打开""保存"按钮显示图标（新增 `assets/icons/New.png`、`Open.png`、`save.png`，更新 `Text.png`、`MText.png`）

## 构建与版本

- 版本号只在根目录 `CMakeLists.txt` 的 `MINICAD_VERSION` 中维护；桌面版的 exe 版本信息（FileVersion / ProductVersion）由构建自动生成（`apps/Win32/src/MiniCADVersion.h.in` → `MiniCAD.rc`），之前写死为 0.0.0.1
- 核心库定义迁入 `cmake/MiniCAD.cmake`，与 `cmake/MiniDWG.cmake`、`cmake/MiniGUI.cmake` 结构一致
- CMake 目标名由 `MiniCADLib` 改为 `MiniCAD`，`apps/Common`、`apps/Win32`、`apps/Web`、`wasm`、`tests` 的链接同步更新；C++ 命名空间 `MiniCADLib` 保持不变
- 仓库忽略规则：`docs` 改为只忽略 `docs/evidence`，发布说明纳入版本控制

## 资源

- `assets/icons/24x24/` 目录移除，界面图标统一使用 `assets/icons/` 下的图标

## 持续集成

- 修复构建在本地专用文件缺失时失败的问题，缺失时跳过相关目标（`tests/CMakeLists.txt`）
