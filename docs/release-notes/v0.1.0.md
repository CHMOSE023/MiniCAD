MiniCAD 的第一个整合版本：MiniCADLib（核心库）、MiniGUI（界面库）、MiniDWG（DWG/DXF 读写库）合并为一个仓库，桌面版与网页版共用同一套界面。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.1.0-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.1.0-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 主要功能

- **绘图**：直线、点、矩形、圆、圆弧、椭圆 / 椭圆弧、多段线、样条曲线、多线、构造线、射线、二维填充、区域覆盖、面域及布尔运算、表格、光栅图像、图案填充
- **修改**：移动、复制、镜像、偏移、旋转、缩放、圆角、倒角、拉伸、修剪、延伸、打断、阵列、分解；夹点编辑；撤销 / 重做
- **标注与文字**：线性、角度、半径、直径、折弯、弧长、坐标标注，引线、多重引线，关联标注；单行 / 多行文字原位编辑，SHX 与 TrueType 字体，文字样式
- **图层与块**：图层（开关、锁定、颜色、线型、线宽），线型，创建块 / 插入块
- **绘图辅助**：对象捕捉、正交、极轴、动态输入、命令行（AutoCAD 式命令与别名）
- **文件**：MiniCAD 文档（.mcad 二进制 / .json）；打开 DWG（R13～2018）与 DXF（R12～2018）；保存为 AutoCAD 2018 或 2013/2014 格式的 DWG / DXF
- **界面**：多文档标签、可停靠的特性 / 图层 / 命令行面板、菜单与工具栏由 `ui/minicad_ui.json` 描述；深色 / 浅色主题（浅色主题下白色图形与光标自动显示为黑色）

## 网页版说明

- 界面与桌面版相同；打开文件使用浏览器的文件选择框，保存时由浏览器下载到本机
- 支持中文输入法（候选窗跟随文字光标）与 Ctrl+V 粘贴系统剪贴板中的文字；有未保存的修改时，关闭或刷新页面前浏览器会询问
- 暂不保存用户拖动后的面板布局

## 已知问题

- DWG / DXF 只映射了 MiniCAD 支持的实体，填充、样条、引线等在导入导出时会跳过
- 自测中有 2 项已知失败（阵列对话框默认值、改颜色后的重新细分），MiniGUI 截图对比测试有 10 个场景的基准图片待更新
