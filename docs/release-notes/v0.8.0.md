# MiniCAD v0.8.0

本版能读取 DWG / DXF 里的三维实体与曲面并着色显示，支持渐变填充，网页版可以从网址打开图纸，Linux 版改为直接使用 X11 / Wayland；还新增了两种界面布局、光标设置与自带的单线 SHX 字体，并修好了繁体、日文、韩文图纸里文字缺字、显示成方块的问题。

### 新增

- **读取三维实体与曲面**：DWG / DXF 里的三维实体（3DSOLID）、面域（REGION）、体（BODY）与各类曲面（拉伸、旋转、放样、NURBS 等）打开后成为三维实体，切到等轴测等三维视图即着色显示；桌面版与网页版都支持
  - 支持 R2000 起各版本的 DWG 与 R2010 及以前的 DXF；曲面类型包括平面、圆柱 / 圆锥、球、圆环与样条曲面
  - 块里的实体（含嵌套块、阵列）同样着色，颜色与图层开关随块参照
  - 个别曲面建不出来时该实体只显示边线，打开后在日志里提示数量；暂不支持椭圆锥面、R2013 起的 DXF 里的实体
  - 未改动的实体另存为同格式、同版本时原样保留；改动过的实体或另存为其他版本时写成多面网格
- **渐变填充**（GRADIENT）：线性、柱面、球面、半球面、曲线等渐变（含反相）与单色渐变按原图显示，以前只画成一块纯色；读写 DWG / DXF 与 .mcad 时保留，特性面板显示渐变类型与角度
- **网页版从网址打开图纸**：网址带 `?open=<图纸网址>`（可带多个）时，界面就绪后自动取回并打开；默认只取本网站的文件，取不到时按原因提示（未登录、无权限、找不到）
  - 嵌入 MiniCAD 的网页可定义 `window.MiniCADHost`：由它取文件（例如加上请求头），并为打开的图纸自动提供外部参照，找不到的再提示选择文件夹
- **更多自定义对象**：带代理图形的 `SWR_*` 对象（墙、柱、门窗、尺寸、轴号、文字等）按代理图形显示
- **界面布局：浮动 / 紧凑**：标题栏右侧"设置 > 布局"里切换，立即生效，面板的位置保持不变，下次启动沿用
  - **浮动**（默认）：功能区、特性 / 图层面板、状态栏是浮在绘图区上的圆角卡片，之间留出缝隙
  - **紧凑**：功能区、面板、状态栏贴着窗口边缘，方角、没有缝，绘图区更大；底部的命令行与状态栏之间仍留一点距离
  - 拖出成独立窗口的图纸跟着一起切换
- **设置光标**（"管理 > 界面 > 设置光标"）：拖动滑块调整，对话框里的预览与绘图区里的光标实时变化，"确定"后下次启动沿用，"取消"还原
  - **十字光标大小** 0～100：十字线占绘图区的百分比，0 只留中间的拾取框，100 铺满绘图区
  - **拾取框大小** 0～50：中间方框的大小，点选、悬停高亮时离光标多近的对象算选中也随它变
  - "恢复默认"回到十字光标 5、拾取框 6
  - 说明：十字光标的默认长度改为占绘图区的 5%，大窗口里比以前略短；想要原来的长度可调到 6～7
- **自带单线 SHX 字体**：`minicad_sc.shx`（简体）、`minicad_tc.shx`（繁体）、`minicad_jp.shx`（日文汉字与假名）、`minicad_kr.shx`（全部 11172 个韩文音节），SHX 文字缺字时自动补上
  - 单线字与 TrueType 填充字不再混排：SHX 样式里缺的字（简体大字体配繁体字、韩文、日文假名等）只从这几个单线字体里找，风格与探索者、天正的单线字一致；都没有时显示"?"（同 AutoCAD）
  - 钢筋符号 %%130～%%133（HPB300、HRB335、HRB400、RRB400）：样式的字体里没有时也能显示
  - 笔画取自 Make Me a Hanzi（Arphic PL）与 KanjiVG（CC BY-SA 3.0），见 THIRD_PARTY_NOTICES.md
- **示例图纸"字体与符号"**：起始页"示例"里新增，列出随程序提供的各个字体、钢筋符号、%%c / %%d / %%p 等控制码与常用工程符号，右侧四张字表列出简体（GB2312 全部 6763 字及其他简体字）、繁体（Big5 已收录的 6854 字）、日文（假名与 6425 个汉字）、韩文（全部 11172 个音节与字母）单线字体收录的每一个字；打开的是副本，保存时另存，不会改动示例本身

### 改进

- **Linux 版不再依赖 SDL3**：直接使用 X11 或 Wayland（有 Wayland 时优先，可用环境变量 `MINICAD_WINDOWING` 指定）
  - 自绘标题栏与窗口按钮，可拖动、缩放窗口；支持输入法、剪贴板与拖放打开图纸
  - X11 下停靠面板与图纸可以拖出成独立窗口
  - 文件对话框走 xdg-desktop-portal，没有时用 zenity
  - 图形优先用 Vulkan，不行时用 OpenGL ES 3

### 修复

- **块参照改了图层 / 颜色 / 线型 / 线宽后，块里的内容不跟着变**：块里 0 层与 ByBlock 的对象现在随之更新，撤销也能还原
- **曲线的虚线**：线型比例较大时，圆、圆弧、椭圆、多段线的虚线不再显示成实线；缩小视图时不再一段一段地缺失
- **块属性**：属性在 0 层时随块参照所在图层；ByBlock 的颜色、线型、线宽随块参照（以前一律显示为白色）；属性按自己的文字样式显示
- **块参照所在图层关闭时**：块里具名图层上的对象按各自图层的开关显示，不再整块消失（同 AutoCAD）
- **法向朝下（-Z）的圆弧、椭圆、多段线**：位置与方向正确，另存为 DWG / DXF 再打开不再镜像
- **繁体、日文、韩文文字缺字**：图纸里用细明体、MS Gothic、Gulim 等字体写的文字，本机没有这些字体时以前常显示成方块，现在按文字体系改用同类字体（微软正黑、Noto Sans CJK 等），仍缺的字再依次到其他字体里找
- **SHX 大字体**：繁体（chineset、big5）、日文（extfont）、韩文（whgtxt）等大字体按各自的编码取字，不再错字或空白；简体大字体里的韩文不再错成汉字（如"어"显示成"糯"）
- **界面文字字形**：日文界面的汉字按日本写法、繁体界面按台湾写法显示，韩文界面不再缺字；网页版切换到繁体或日文时按需下载对应字体
- **英文界面的单复数**：如"1 object / 2 objects"按数量显示
