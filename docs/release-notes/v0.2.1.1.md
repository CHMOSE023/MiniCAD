# MiniCAD v0.2.1.1

v0.2.1.0 之后的版本。主要新增桌面版的三维实体建模（SMLib 内核），DWG / DXF 另存可选 2000～2018 各版本，并修回 v0.2.0 重写时退化的轴号、多段线线宽与凸度方向。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.2.1.1-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.2.1.1-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 三维实体建模（桌面版）

接入 SMLib 实体建模内核（经 `ISolidKernel` 接口，核心库不依赖具体内核），新增三维实体 `Solid3DEntity`。开发计划与细节见 `docs/Solid/PLAN.md`。

- **建模命令**（"建模"菜单与命令行）：长方体、圆柱、球、拉伸（EXTRUDE）、旋转（REVOLVE）、扫掠（SWEEP）、实体并 / 差 / 交、边圆角（FILLETEDGE）、边倒角（CHAMFEREDGE）；俯视图里点选边，Tab 切换重叠的边。全部可撤销
- **三维出二维图**：截面（SECTION）、平面投影（FLATSHOT，隐藏线消除），结果拟合为直线 / 圆弧 / 圆，可直接标注
- **三维视图**：标准视图与等轴测、Shift + 中键环绕、着色 / 线框、被遮挡的边不显示、随视角变化的轮廓线；绘图区右上角的视图方块（点面、棱、角或东南西北切换视角，拖动环绕；NAVVCUBE / VIEWCUBE 开关）
- **读写**：`.mcad` / JSON 保存内核数据；DWG / DXF 导出为多面网格（AutoCAD 里看到的线框与实体的边一致），读入时多面网格不转回实体
- 网页版暂不带内核：能显示、移动、原样保存含三维实体的图纸，建模命令提示"不可用"

## DWG / DXF 另存版本

- 另存为可选 **2018、2013/2014、2010、2004、2000** 的 DWG，以及同样各版本加 **2007** 的 DXF；桌面版系统对话框与网页版另存为对话框用同一张格式表
- 新建文档默认写出 **2004** 版；打开的图纸保存时仍沿用原版本
- 2007 以前的版本按 `ANSI_936`（GBK）代码页写出，中文文字不再变成问号
- 2007 格式的 DWG 暂不能写出（MiniDWG 没有实现 AC1021 的写出），界面上不提供；打开 2007 DWG 后直接保存会改写为 2010 格式并在日志里提示

## 界面

- 工具栏的图层 / 线型 / 线宽下拉框跟随选择集（同 AutoCAD 特性工具栏）：选中对象时显示对象的值，取值不同显示"\*多种\*"，在下拉框里选择即修改选中对象；没有选择时仍是当前值（作用于新建对象）
- 绘图区有焦点时 Alt + 字母（如 Alt+F）可以打开对应菜单；之前按键被绘图区与命令行截走
- 新增"文件 > 最近打开"（最多 10 条，按最近使用排序，重名时显示父目录名）
- 修复网页版工具栏的保存按钮不显示（图标文件名大小写）

## 修复（v0.2.0 重写时退化，按 v0.1.0 修回）

- **轴号（块属性）**：导入 ATTDEF / ATTRIB，属性位置与对齐方式正确，可变属性的模板不再多画一个"A"，空值属性不画字
- **多段线逐段线宽**（DXF 40 / 41）：按段保存起止宽度，梯形填充、转角斜接；有宽度即画成带子
- **多段线凸度方向**（DXF 42）：圆弧不再沿弦镜像到另一侧；交互绘制圆弧段、拖动弧中点夹点、按切向求凸度三处入口一并修正
- **放大图面时鼠标跳到原点**：大图纸放大到很大倍数时，矩阵求逆把良态矩阵误判为奇异，鼠标坐标、捕捉点、新建对象全部落到原点
- **中文路径**：图片、SHX / TTF 字体在中文路径下打不开或导致崩溃

## 构建与 CI

- 版本号支持四段（本版 `0.2.1.1`）：exe 的产品版本为 `0.2.1.1`，文件版本仍为前三段加构建号（git 提交数），例如 `0.2.1.175`
- CI 只在推送 `v*` 标签时自动运行（编译、测试、打包、创建 Release，网页版部署到 Cloudflare Pages）；推送分支和 PR 不再自动运行，需要时在 Actions 页面手动运行
- 桌面版构建多了 SMLib 静态库，首次编译时间明显变长

## 测试

- 新增 DWG / DXF 2000、2004、2007、2010 往返测试（含中文文字）；三维相关的 `SMLibSmokeTests`、`SolidKernelTests`、`Solid3DEntityTests`、`SolidToolTests`、`SolidDrawingTests`、`SolidViewTests`；轴号、多段线线宽、凸度方向的测试
- 桌面版自测新增：工具栏图层框跟随选择集、绘图区 Alt+F 打开菜单

## 已知问题

- 桌面版自测在本机有 17 项失败（多为注入鼠标移动、中键平移、滚轮、点选的用例，以及阵列对话框默认值、改颜色后的重新细分），本版改动之前就存在
- 截图对比测试 `MiniGUIGolden` 有 10 个场景与基准图不一致（标题栏、停靠、文档标签），CI 不运行该测试
- 2007 格式的 DWG 不能写出（见上）
- 网页版没有三维建模内核
