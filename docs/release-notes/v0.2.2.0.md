# MiniCAD v0.2.2.0

v0.2.1.3 之后的功能版本：新增**节点式参数化建模**（节点图），用节点和连线搭建可调参数的模型，改一个参数，绘图区实时更新，结果可“烘焙”成图纸里的对象；三维实体内核增加空间 NURBS 曲线与开放曲面，新增多面网格实体。桌面版与网页版都包含节点图（网页版没有三维实体内核，见下文）。

## 下载

| 文件 | 说明 |
|---|---|
| `MiniCAD-v0.2.2.0-windows-x64.zip` | Windows 桌面版（D3D11）。解压后运行 `MiniCADWin.exe`，不需要安装运行库 |
| `MiniCAD-v0.2.2.0-web.zip` | 网页版（WebAssembly + WebGL2）。把里面的 `index.*` 放到任意静态网站，用支持 WebGL2 的浏览器打开 `index.html`（不能直接双击本地文件） |

## 新功能

### 节点式参数化建模（视图 → 面板 → 节点编辑器）

- **节点编辑器**：停靠在绘图区下方的面板。Tab 或双击空白处搜索添加节点，空白处右键按分类添加；从端口拖出连线（只列出能连上的节点）；Alt + 单击端口断开；框选、复制粘贴（Ctrl+C / X / V）、创建副本（Ctrl+D）、撤销重做
- **实时预览与烘焙**：没有连到下游的输出直接显示在绘图区（实体着色、空心橙色线框，选中节点时高亮）；“烘焙”把结果加入图纸，一步撤销
- **170 多种节点**，分为输入、图纸、数学、列表、向量、曲线、曲面、实体、网格、变换、组：
  - 数学与列表：表达式（公式里可直接引用命名参数）、序列、区间、最长列表匹配与交叉引用
  - 曲线：直线、圆弧、多段线、正多边形、椭圆、NURBS 插值 / 拟合 / 控制点曲线、螺旋线；偏移、圆角、分割、延伸、连接、投影、重建；等分、求交、最近点
  - 曲面（参照 Grasshopper）：放样、直纹、旋转、扫掠（单轨 / 双轨）、边界、网络、点阵、参数曲面；偏移、加厚、修剪、分割、拼接、封口；等参线、曲率、求交
  - 实体（参照 Revit 族编辑器）：拉伸、旋转、放样、融合、放样融合及对应的**空心**形体，形体合并、剪切几何；布尔、圆角、倒角、抽壳、分割、截面
  - 网格：创建（长方体、球、平面、Delaunay、由曲线）、细分、光顺、简化、焊接；网格截面、网格边、轮廓线、网格求交；实体 ↔ 网格互转
  - 引用图纸里的曲线、点、三维实体：图纸改了，节点图跟着重算
- **命名参数、公式与类型**：“参数”表集中编辑全部参数的名称、类别、值、公式，可保存多组参数为“类型”（族类型）并切换
- **组节点**：选中节点 Ctrl+G 收成一个组（子图），双击进入编辑，修改同步到这个组的全部实例；Ctrl+Shift+G 解组。组可以嵌套
- **后台求值**（桌面版）：大模型在后台线程计算，拖滑块时界面不卡、能连续看到中间结果；轻量的图仍在当帧算完。工具行“停止”可中止求值
- **随图纸保存**：节点图存进 `.mcad` / JSON；也可以经节点面板的“文件”菜单单独保存 / 打开节点图文件（`.mcnode`），在不同图纸之间复用（打开时可插入或替换）
- **示例**：工具行“示例”菜单——基础四张（曲线：圆角、偏移与等分；曲面：放样、参数曲面与旋转；实体：法兰座；网格：地形与光顺），应用四张（参数化窗框、曲面屋顶、网格化导出、网格截面与求交）。示例以 `.mcnode` 文件随程序发布（`nodes/examples/`）

### 三维与网格

- **空间 NURBS 曲线与开放曲面**：开放曲面可以着色显示、烘焙、保存，导出 DWG / DXF 时写成多面网格
- **多面网格实体**（`MeshEntity`）：节点图的网格可以烘焙成图纸对象，与 DWG / DXF 的多面网格（PolyfaceMesh）互相读写

### 界面

- 状态栏右侧显示发布版本；“帮助 → 关于”显示正确的版本与文件版本（以前固定显示“版本 1.0”）

## 说明

- 网页版没有三维实体内核：曲线、数学、列表、网格节点照常工作，实体与曲面节点提示“内核不可用”，示例菜单里需要内核的示例显示为禁用；网页版的节点图在界面线程上同步求值
- 三维实体内核（SMLib）不能并发使用，桌面版的后台求值与界面线程轮流调用内核；单个很重的内核运算（如大布尔）中途不能打断
