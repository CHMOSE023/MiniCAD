# MiniCAD v0.3.1

本版以大图纸的显示与编辑性能为主，另有起始页、节点、多段线与图层面板的完善。

### 性能

- **滚轮缩放**：虚线的几何改在世界坐标里生成，缩放时不再重新细分虚线所在的实体；特别长的虚线（超过 200 个周期）延迟铺设，只按当前缩放重铺这些段，一个周期不足 4 像素时画成实线。每格滚轮：管综 56 → 15 ms，8#楼 40 → 14 ms
- **切换文档**：每个文档有自己的编辑器，显示数据、选择集、工具状态随文档保留，切回时只重新拼接显示数据，不重新细分。切回首帧：管综 339 → 64 ms，8#楼 149 → 30 ms
- **框选全图**：先用包围盒粗筛，块、标注、填充的精确判定使用缓存；选中显示从已有的显示数据复制，不重新细分；特性面板与工具栏的选择集统计按版本缓存。管综框选全图：抬起 248 → 75 ms，选中后首帧 416 → 84 ms，之后每帧 87 → 7 ms，带选择集滚轮 366 → 20 ms
- **夹点**：同 AutoCAD 的 GRIPOBJLIMIT，选中超过 100 个对象时不显示夹点；夹点几何按内容缓存
- **下拉框**：最宽条目的宽度按条目缓存，图层很多的图纸选择集变化时不再每次重新测量所有图层名

### 完善

- **起始页**：左侧导航列的“节点编辑器”现在会回到图纸（没有图纸时新建）并显示节点面板；“节点建模”卡片和示例在节点面板已打开时不再把它收起
- **打开图纸**：开始读取就进入绘图区，状态栏显示读取进度，不用等大图纸读完才离开起始页；没有打开任何图纸时也能看到进度
- **图层面板**：新增搜索框（不分大小写，Esc 清空）；点“名称”表头切换升序 / 降序；图层在面板、特性面板和工具栏下拉框里都按名称的自然顺序排列（0 层最前）
- **停靠面板**：标签上角改为圆角，激活的标签与面板内容同色连成一片
- **拉伸节点**：轮廓支持椭圆、样条曲线和多段线（不闭合的多段线按首尾相连处理）
- **多段线**：输入 C 闭合，圆弧模式下用经过弧上点的圆弧连回起点
- **命令行**：支持 AutoCAD 命令全名 `PLINE`、`RECTANG`、`DTEXT`、`DIMLINEAR`、`DIMALIGNED`

### 修复

- 网页版编译：起始页不再使用 libc++ 没有的 `clock_cast`
- 从起始页点击节点编辑器后面板不显示
- 大图纸首次打开时绘图区不显示

### 开发与测试

- MiniGUI 截图对比基准按 v0.3.0 的界面样式更新，全部场景通过
- 节点图测试按功能拆分为多个文件（`NodeGraph*Tests.cpp`、`NodeSolid*Tests.cpp`）
- 新增多段线工具测试、线型缩放测试；桌面版 `--bench` 增加平移与框选全图测量
