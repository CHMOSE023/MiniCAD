# MiniCAD v0.3.1

### 完善

- **起始页**：左侧导航列的“节点编辑器”现在会回到图纸（没有图纸时新建）并显示节点面板；“节点建模”卡片和示例在节点面板已打开时不再把它收起
- **打开图纸**：开始读取就进入绘图区，状态栏显示读取进度，不用等大图纸读完才离开起始页；没有打开任何图纸时也能看到进度
- **拉伸节点**：轮廓支持椭圆、样条曲线和多段线（不闭合的多段线按首尾相连处理）
- **多段线**：输入 C 闭合，圆弧模式下用经过弧上点的圆弧连回起点
- **命令行**：支持 AutoCAD 命令全名 `PLINE`、`RECTANG`、`DTEXT`、`DIMLINEAR`、`DIMALIGNED`
