# MiniCAD v0.8.1

本版修好了天正图纸的几处显示问题：另存为代理实体的天正图纸大部分内容不显示，门窗编号缺失，弧墙与其他墙相接处断开或穿过。

### 修复

- **天正对象另存为代理实体的图纸大部分内容不显示**：墙、柱、门窗、尺寸、轴号等对象以前因为图形里的图层 / 线型记录读不懂而整个跳过，现在按各自的图层与线型显示
- **天正门窗编号不显示**：普通门窗（不只是组合门窗、带形窗）也画编号，文字沿门窗方向并转成正读，放在编号图层上
- **天正弧墙与其他墙相接**：弧墙两侧按连接量截短或延长，与直墙、弧墙相接及十字交叉处不再断开或穿过
- **天正墙相接处多出接缝**：相接的墙里有同材料的就不画分界线，只在全是其他材料时才画
