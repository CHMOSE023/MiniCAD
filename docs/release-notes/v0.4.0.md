# MiniCAD v0.4.0

本版重写了渲染层：每个平台编译自己的原生图形接口——Windows 默认 Direct3D 12，网页默认 WebGPU，并新增 Linux 版（默认 Vulkan，不行时 OpenGL ES 3）。各平台都保留回退，没有显卡的电脑上也能运行。

### 新增

- **Linux 版**（`MiniCAD-v0.4.0-linux-x64.tar.gz`）：界面与 Windows 版、网页版相同，窗口与输入用 SDL3，X11 与 Wayland 都能用
  - 图形默认 Vulkan（要 Vulkan 1.3），驱动不支持或建不起来时自动改用 OpenGL ES 3；没有显卡时用 Mesa 的软件实现（lavapipe / llvmpipe）
  - 打开、保存文件用系统的文件对话框（xdg-desktop-portal，没有时 zenity）；也可以把图纸拖进窗口，或在命令行上给出：`./MiniCADLinux 图纸.dwg`
  - 窗口用系统的标题栏和边框
  - 运行需要 64 位 Linux（glibc 2.38、GCC 13 的 libstdc++ 以上，如 Ubuntu 24.04、Debian 13、Fedora 39）以及 Mesa 的 EGL / OpenGL ES 与 Vulkan 加载器（Ubuntu 上是 `libegl1`、`libgles2`、`libvulkan1`，桌面系统一般都已装好）。SDL3 已链入程序，不用另装
  - 目前只在虚拟显示（Xvfb）与软件渲染下验证过，真实显卡、Wayland、输入法、高 DPI 还没有实际试过，欢迎反馈
- **Windows 版默认用 Direct3D 12**：按 D3D12 → D3D11 → WARP（微软的软件渲染）的顺序创建，前一个不可用就用下一个；画面与 D3D11 逐像素相同
  - 布局页平移每帧 10.5～11.2 → 4.1 ms，其余操作持平；内存与 D3D11 相当（启动时多 4%～5%，打开大图纸后持平或更少）
  - 大图纸上需要一次上传大量数据的那一帧（框选全图后的第一帧、切回文档）比 D3D11 慢约 10～40 ms
  - 遇到显示问题可以退回 D3D11：命令行加 `--gpu d3d11`，或设环境变量 `MINICAD_GPU=d3d11`（还可以是 `d3d12`、`warp`）
- **网页版默认用 WebGPU**：浏览器不支持时自动改用 WebGL2；网址加 `?webgl` 强制用 WebGL2。Chrome / Edge 上已验证，画面与 WebGL2 一致；Firefox 141 起、Safari 26 起默认开启 WebGPU，更早的版本自动走 WebGL2。程序体积只多约 85 KB
- **关于对话框显示图形接口**：例如"图形 D3D12"、"图形 WebGPU (nvidia pascal)"、"图形 Vulkan (…)"，排查显示问题时可以先看这一行

### 修复

- **从别的目录启动时 CAD 字体找不到**：随程序带的 SHX / TrueType 字体以前按"当前目录下的 `fonts/`"找，从命令行在别的目录启动、或经快捷方式指定了其他工作目录时，图纸里的文字用不上自带字体。现在按程序所在目录的 `fonts/` 找，与从哪里启动无关
- **同一张图纸两次打开，画面偶尔不一样**：宋体（simsun.ttc）的空格是只有一个点的字形轮廓，`stb_truetype` 处理这种轮廓时越界读内存，空格画成一串位置随机的长斜线（布局页里最明显）。已修复（对 `3rd/stb/stb_truetype.h` 的本地修改，记录在 `3rd/stb/README.md`）

### 开发与测试

- 渲染代码集中到 `apps/Render`，每个平台只编译自己的后端（`cmake/Render.cmake`）。宿主只经图形设备接口 `IGraphicsDevice` 使用图形接口，`CreateGraphicsDevice` 按平台的顺序创建并回退；`IRenderer` / `IRenderTarget` / `MiniGUI::IRenderBackend` / `AppPlatform` 都没变。计划与各阶段的验收数据见 `docs/Render/PLAN.md`
  - Windows：`D3D12GraphicsDevice`、`D3D11GraphicsDevice`，两者共用 `apps/Render/Hlsl/` 里的 HLSL
  - 网页：`WebGPUGraphicsDevice`（经 Emscripten 的 emdawnwebgpu 绑定，第一次构建要联网下载）、`GLES3GraphicsDevice`
  - Linux：`VulkanGraphicsDevice`（GLSL 着色器构建时用 glslangValidator 编成 SPIR-V）、`GLES3GraphicsDevice`；宿主 `apps/Linux`，平台层 `src/UI/Platform/SDL`
  - 原来网页版的界面后端 `WebGL2Backend` 改名 `GLES3Backend`
- `MiniGUIGolden` 增加 D3D12 与软件光栅的截图对比
- 核心库与测试能用 GCC 13 编译（几处同名成员与类型、头文件、SMLib 一处析构函数写法的可移植性修改，Windows 行为不变）
- CI 新增 **Linux** 任务：编译 SDL3、MiniCAD 与测试，运行测试，打包 `MiniCAD-<标签>-linux-x64.tar.gz`；发布时随 Windows 版、网页版一起上传
- 曾经验证过的 wgpu-native 渲染原型因内存开销过大放弃（D3D12 后端启动就多约 500 MB），代码没有保留，结论记在 `docs/WebGPU/PLAN.md`
