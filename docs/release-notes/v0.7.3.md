# MiniCAD v0.7.3

本版新增两种界面布局、光标设置与自带的单线 SHX 字体，并修好了繁体、日文、韩文图纸里文字缺字、显示成方块的问题。

### 新增

- **界面布局：浮动 / 紧凑**：标题栏右侧"设置 > 布局"里切换，立即生效，面板的位置保持不变，下次启动沿用
  - **浮动**（默认）：功能区、特性 / 图层面板、状态栏是浮在绘图区上的圆角卡片，之间留出缝隙
  - **紧凑**：功能区、面板、状态栏贴着窗口边缘，方角、没有缝，绘图区更大；底部的命令行与状态栏之间仍留一点距离
  - 拖出成独立窗口的图纸跟着一起切换
- **设置光标**（"管理 > 界面 > 设置光标"）：拖动滑块调整，对话框里的预览与绘图区里的光标实时变化，"确定"后下次启动沿用，"取消"还原
  - **十字光标大小** 0～100：十字线占绘图区的百分比，0 只留中间的拾取框，100 铺满绘图区
  - **拾取框大小** 0～50：中间方框的大小，点选、悬停高亮时离光标多近的对象算选中也随它变
  - "恢复默认"回到十字光标 5、拾取框 6
  - 说明：十字光标的默认长度改为占绘图区的 5%，大窗口里比以前略短；想要原来的长度可调到 6～7
- **自带单线 SHX 字体**：`minicad_sc.shx`（简体）、`minicad_tc.shx`（繁体）、`minicad_jp.shx`（日文汉字与假名）、`minicad_kr.shx`（全部 11172 个韩文音节），SHX 文字缺字时自动补上
  - 单线字与 TrueType 填充字不再混排：SHX 样式里缺的字（简体大字体配繁体字、韩文、日文假名等）只从这几个单线字体里找，风格与探索者、天正的单线字一致；都没有时显示"?"（同 AutoCAD）
  - 钢筋符号 %%130～%%133（HPB300、HRB335、HRB400、RRB400）：样式的字体里没有时也能显示
  - 笔画取自 Make Me a Hanzi（Arphic PL）与 KanjiVG（CC BY-SA 3.0），见 THIRD_PARTY_NOTICES.md
- **示例图纸"字体与符号"**：起始页"示例"里新增，列出随程序提供的各个字体、钢筋符号、%%c / %%d / %%p 等控制码与常用工程符号，右侧四张字表列出简体（GB2312 全部 6763 字及其他简体字）、繁体（Big5 已收录的 6854 字）、日文（假名与 6425 个汉字）、韩文（全部 11172 个音节与字母）单线字体收录的每一个字；打开的是副本，保存时另存，不会改动示例本身

### 修复

- **繁体、日文、韩文文字缺字**：图纸里用细明体、MS Gothic、Gulim 等字体写的文字，本机没有这些字体时以前常显示成方块，现在按文字体系改用同类字体（微软正黑、Noto Sans CJK 等），仍缺的字再依次到其他字体里找
- **SHX 大字体**：繁体（chineset、big5）、日文（extfont）、韩文（whgtxt）等大字体按各自的编码取字，不再错字或空白；简体大字体里的韩文不再错成汉字（如"어"显示成"糯"）
- **界面文字字形**：日文界面的汉字按日本写法、繁体界面按台湾写法显示，韩文界面不再缺字；网页版切换到繁体或日文时按需下载对应字体
- **英文界面的单复数**：如"1 object / 2 objects"按数量显示
