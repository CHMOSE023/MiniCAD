# MiniCAD v0.5.1

本版主要改进浮出的停靠面板：浮动窗口能最大化，一键占满第二台显示器；几个浮出的面板能合并进同一个窗口，成为标签，规则与主窗口的停靠区相同。同时修复了别的面板浮出时、已浮出的节点编辑器窗口变空的问题。另外合入了 PR #23：含文字 / 形符号的复杂线型能画出符号，射线、构造线、引线、形位公差、光栅图像、表格、形等实体能导入。

### 新增

- **浮动面板能最大化**：浮出的面板窗口标题栏上（× 左边）多了最大化 / 还原按钮
  - Windows 版最大化到窗口所在的那台显示器；最大化时拖标题栏，窗口先还原再跟着光标走
  - 最大化状态与还原后的位置随面板布局保存，下次启动时恢复
  - 网页版、Linux 版的面板在主窗口内浮动，最大化是铺满主窗口
- **浮动窗口里也能停靠、合并标签**：每个浮动窗口都有自己的停靠布局，规则与主窗口的停靠区一样
  - 把面板标签，或者整个浮动窗口（拖它的标题栏），拖到另一个浮动窗口的标题栏或标签条上，就合并成标签；拖到内容区，按位置拆分或合并（画落点预览）
  - 浮动窗口里的标签能拖出来：拖出窗口就浮出成新窗口，也能拖回主窗口的停靠区或别的浮动窗口
  - 窗口里只有一个面板时不显示标签条，看起来和以前一样
  - 双击浮动窗口的标题栏，里面的面板都回到停靠区原来的位置；双击其中一个标签，只让那个面板回去
  - 窗口的 × 关掉里面所有面板；之后从"视图 > 面板"再打开，回到原来的浮动窗口
- **复杂线型画出文字和形符号**（PR #23）：TRACKS、ZIGZAG、BATTING、GAS_LINE、FENCELINE 这类线型按线型定义在每段末尾画出文字或形，每个周期都画（以前只画虚线部分）
  - 形取自线型引用的形文件，程序附带了 AutoCAD 线型用的 `ltypeshp.shx`；形只描边不填充，与 AutoCAD 相同
  - 符号随图纸缩放，不随视图缩放重新铺设；一段线上周期太多时与普通虚线一样画成实线
  - 线型对话框与图层面板的线型预览也画出符号
- **更多实体能打开、另存**（DWG / DXF，PR #23）
  - 射线（RAY）、构造线（XLINE）、引线（LEADER）、形位公差（TOLERANCE）、光栅图像（IMAGE，含旋转）：以前打开时被跳过，现在能读能写
  - 表格（ACAD_TABLE）按它的匿名块还原外观，另存时写成块参照
  - 形（SHAPE）能读入，找不到形时画占位方框（与找不到文件的图像相同），不会凭空消失；另存时不写出

### 修复

- **别的面板浮出后，已浮出的面板窗口变空**：例如节点编辑器先浮出，再浮出特性面板，节点编辑器窗口里的菜单和内容就全没了。现在已浮出的窗口不受影响，内容和焦点都保留
- **主窗口开着对话框时，文档窗口里的面板仍能操作**（Windows 版，v0.5.0 引入）：点文档窗口里的特性、图层面板，焦点会移进去，之后按 Esc 关不掉对话框，还能在对话框底下改图层。现在对话框开着时，文档窗口和浮出的面板窗口都不接受鼠标，点一下只把主窗口（连同对话框）置前，按键与输入都交给对话框
- **SHX 字体读失败一次，之后一直显示为空**（PR #23）：某次没读进来的字体会被记住，之后整个会话都用空字体（线型符号、文字不显示，切换图纸后才恢复）。现在读失败的字体下次用到时会重新读
- **SHX 字形里的八分圆弧画错**（PR #23）：圆弧的起始位置与方向解码有误（例如 `ltypeshp.shx` 里 BAT 形画成散开的乱线）。普通文字字体里很少用到八分圆弧，几乎不受影响

### 开发与测试

- MiniGUI：
  - `DockSpace` 每个浮动窗口一棵布局树（`DockFloatView` 作为窗口内容交给 `IDockFloatHost`）；`IDockFloatHost` 新增 `IsFloatMaximized` / `SetFloatMaximized` / `GetRestoreRect` / `ToDock` / `FromDock`；`FloatingPanel` 标题栏加最大化按钮
  - 布局 JSON 的 `floatingPanels` 每项可以是一组标签或拆分（`tabs` / `split`，加 `rect`、`maximized`），只有一个面板的旧格式照常读
  - `UIContext::SetModalOwner`：程序的次窗口随所有者窗口的模态对话框一起阻塞（指针不进，按键、文字与输入法组合串转给所有者）
- `IFloatingWindow::GetRestoreRect`；Windows 版的面板窗口能最大化（仍不能最小化）
- 新增实体 `ShapeEntity`；线型的文字 / 形段记在 `LineTypeRecord::Symbols`，导出时写回
- 桌面版自测第 29、30 节恢复全部通过（v0.5.0 里第 29 节失败、第 30 节随后崩溃）；第 30 节的文档窗口没建出来时跳过本节其余部分，不再崩溃。第 31 节补两个面板先后浮出、拖标题栏合并、最大化与还原
- 单元测试补浮动窗口的布局（7 个，含每个浮动窗口一个独立 `UIContext` 的情形）、所有者模态（1 个）、带符号的线型、引用类实体的导入导出
