# MiniCAD v0.3.3

本版完善外部参照（XREF）：找不到的参照在图中显示路径，打开后提示并可选文件夹查找；网页版可以经浏览器授权读取本地文件夹里的参照文件。

### 新增

- **未加载的外部参照显示路径**：参照文件找不到或读取失败时，块参照在插入点写出图纸里保存的参照路径（同 AutoCAD），字高按屏幕 14 像素固定，图纸单位多大都看得清；范围取插入点，“全部显示”不会漏掉它。已卸载的参照（组码 71）照旧不显示，卸载标志现在读入，随 `.mcad` / JSON 保存，另存为 DWG / DXF 时写回
- **找不到参照时提示**：打开的图纸有找不到的外部参照时弹框列出参照名与保存的路径，可以“选择文件夹…”在里面查找并读入；仍有找不到的会再列出来，可以换一个文件夹。之后也可以用“文件 > 查找外部参照”或命令行 `XREF`
- **网页版读取本地文件夹里的参照**：上传的图纸旁边没有参照文件，现在可以选择参照所在的文件夹（或它的上级文件夹）。Chrome / Edge 经目录授权（`showDirectoryPicker`）逐级查找，只读取需要的参照文件；其他浏览器退回“上传文件夹”（`<input webkitdirectory>`，浏览器会询问是否上传整个文件夹，但也只读取需要的文件的内容）。文件按原来的子目录放进内存文件系统，相对路径、其他子文件夹里的参照都能找到
- **桌面版选择文件夹**：同一入口在桌面版用系统的文件夹对话框

### 改进

- **查找参照文件**：以前只试保存的路径（相对路径按宿主目录）和宿主目录里的同名文件。现在找不到时再按路径末尾的几段在宿主目录及其各级上级目录里找，末尾相同的段数越多越优先：整个项目拷到别的盘或别的目录（参照存的是原电脑上的 `D:\项目\共用\xref\轴网.dwg`，现在在 `E:\备份\项目\...`）时自动找到。在用户选的文件夹里先按路径后缀、再递归按文件名找，有多个同名文件时取与保存路径最接近的

### 开发与测试

- `CadXrefTests` 增加不依赖本机图纸的部分（在临时目录里现做宿主与参照图纸）：原电脑上的绝对路径按后缀找到、找不到的参照在插入点写出路径且范围取插入点、`ReloadUnresolvedXrefs` 在指定文件夹里递归找到并读入、卸载的参照不读不显示且标志随 DWG 往返
- 新增 `tests/Web/FolderPickerTests.cjs`：用模拟的浏览器运行网页版选择文件夹的 JS，核对目录授权的逐级查找与按文件名筛选、取消、`webkitdirectory` 退回时保留子目录
- 核心库新增 `FindUnresolvedXrefs` / `ReloadUnresolvedXrefs`（`Import/CadExchange.h`）与 `BlockEntity::IsUnresolvedXRef`；平台接口新增 `AppPlatform::PickFolder`
- AI 编程助手的说明改为 `AGENTS.md`（`CLAUDE.md` 只导入它），补充材料放在 `.agents/`：skill `test`（按改动编译并运行相关测试，只返回汇总）与 `drawing-debug`（排查图纸显示问题），按功能分的实现指南，按现象查的排错文档，以及核对文档与代码是否一致的脚本 `check-docs.ps1`
- 删除过时的 `TODO.md`、`docs/BUILD_WASM.md`（描述的是旧版 WASM 接口）与几份已完成的修复记录
